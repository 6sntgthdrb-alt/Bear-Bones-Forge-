# Bear Bones Forge

A personal Warhammer 40,000 (10th edition) list builder, rules viewer and game tracker.

This repository holds only the app. It contains no rules text or artwork. Each person loads their own data on the app's **Data** tab:

- the Wahapedia data files (Datasheets.csv and the rest), from wahapedia.ru
- a missions file, if you have one
- any army icons you want to use

Everything you load or build is saved in your browser on that device. Use **Save backup file** / **Load backup file** on the Data tab to move lists and icons between devices.

Rules data powered by Wahapedia. Warhammer 40,000 is © Games Workshop. This is an unofficial fan tool.
